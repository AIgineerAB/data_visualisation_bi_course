# Data Visualization Course

In this course, you'll dive into: 
- data visualization
- data storytelling

For this you will be using the following tools:
- Power BI
- Python
  - streamlit
  - pandas
  - matplotlib
  - duckdb

Prerequisites for this course are:
- Python fundamentals
- Pandas fundamentals
