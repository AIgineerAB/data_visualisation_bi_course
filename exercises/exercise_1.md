## 1. Bike Order Report

We will continue working with the bike order semantic model created in exercise_0. You can create a new report for this exercise or new pages on the existing report you have created in the lecture or in-class exercises. 

You need to create different visualizations to analyze the revenue and inventory of the bike stores. Below are the requirements coming from the stakeholders. In order to fulfill the requirements from the stakeholders, you need to expand your semantic models with more csv files coming from [Kaggle](https://www.kaggle.com/datasets/dillonmyrick/bike-store-sample-database?select=orders.csv). After adding more csv files to the semantic model, you also need to create new relationships between the tables. Select the correct csv files to be added to the semantic model based on the requirements below. 

&nbsp; a) **Revenue**. Select and add appropriate visuals on the report to present:
- total revenue (after considering the discount) for all orders
- total quantity of products ordered
- total quantity of products ordered by brand names
- total revenue by stores and staff. On this visuals, create a custom tooltip so that a distribution of order status is shown for each store and staff when hovering over the data points

&nbsp; b) **Inventory**. Select and add appropriate visuals on the report to present:
- quantity in stock of each product by brands and stores (preferrably using drilldown on one visual)
