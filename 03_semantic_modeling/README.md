# Getting data into Power BI

## Data sources
Our data sources are two csv files that you can find under the *data* subfolder. The *salaries.csv* comes from Kaggle and have salaries data of data engineer in 2024. You can learn more about the data [here](https://www.kaggle.com/datasets/chopper53/data-engineer-salary-in-2024?resource=download). The second file, *countries.csv*, is generated by LLM which provides mappings of country code to countries/territories and continents.
